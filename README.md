Центр обеих карт — центроид корпусов ЖК «Мечта». Км по дуге, не по дороге. Кольца 12 / 22 / 40 км.

## Сделки (Дом.рф)

Цвета: красный — Мечта · зелёный — кольцо A · жёлтый — кольцо B (Химки / Куркино) · синий — зеленоградский коридор · серый — прочие.

**Химки Тайм** в выгрузке Dom.rf назван «Тайм» — на карте рыночное имя.

Источник: наш.дом.рф / Про Дома (МО 2026-09-29 + Москва 2026-10-01). Слой сделок обновлён 2026-10-02.

## Полка (Новостройкер)

Витрина **Московской области** + **север** (Химки / Зеленоград / Молжаниново) + **запад** (Одинцово / Красногорск / СЗАО / ЗАО / НАО) + кольцо A (Катуар / Шолохово — мониторинг ДМП). Центр Москвы и лоты выше ~750 тыс. ₽/м² не клали.

Цвета: красный — Мечта · зелёный — дешевле Мечты ≥20 тыс. ₽/м² · жёлтый — рядом · синий — дороже ≥20 тыс.

Мечта: медиана МКД свободных из прайса ДМП октября (**~240** тыс. ₽/м²). Область в каталоге **230**.
