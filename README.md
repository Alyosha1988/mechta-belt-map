## Полка (Новостройкер)

Цвета: красный — Мечта · зелёный — дешевле Мечты ≥20 тыс. ₽/м² · жёлтый — рядом · синий — дороже ≥20 тыс. · серые точки — нет в каталоге Новостройкера (в попапе может быть старый слой Дом.рф).

Мечта: медиана МКД свободных из прайса ДМП октября (**~240** тыс. ₽/м²). Область в каталоге **230**. Катуар / Шолохово — мониторинг ДМП (в каталоге нет).
